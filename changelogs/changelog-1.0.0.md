# Custom Gear 1.0.0

*NeoForge and Fabric 1.21.1*

> **First release.** Add armor sets, weapons, tools, food, items, blocks, fluids and storage to Minecraft with JSON files. No coding required.

## ✨ Features

- **NeoForge and Fabric.** The same features and the same content files on both loaders, Minecraft 1.21.1
- **Content types**: armor sets, weapons (swords, bows, crossbows, shields), tools, food, items, blocks, fluids and containers (barrels, chests, shulkers, backpacks)
- **Wearable backpacks** in Curios slots on NeoForge and Trinkets slots on Fabric, through `accessory_slots`. Slots can be written the Curios way (`back`) or the Trinkets way (`chest/back`); the ones both mods ship are translated for the other
- **Recipes, tags, mob drops and damage resistances**, all from JSON, with recipes shown in JEI
- **Content packs**: ship everything as a single `.zip` in `.minecraft/customgear/packs/`
- **Multiplayer verification** of content files at login, and `/customgear reload` to apply changes without restarting
- **Config files**: `config/customgear-common.toml` and `config/customgear-client.toml`
