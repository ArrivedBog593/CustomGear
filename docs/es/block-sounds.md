# Tipos de sonido de bloque

Lista completa de los valores disponibles para el campo `sound` en los JSON de bloque.

> **Uso:** `"sound": "stone"`
> Si el valor no se reconoce o se omite, se usa `stone`.

---

| Valor               | Descripción         |
|---------------------|---------------------|
| `stone`             | Piedra, adoquín     |

| `suspicious_sand`   | Arena sospechosa    |
